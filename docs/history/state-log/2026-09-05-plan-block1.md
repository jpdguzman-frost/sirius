## Decisions taken here (reversible, reported to JP, vetoable)

- **D1** Main-card urgency/difficulty stay STORED and RECONCILED from the main
  card's own Trello labels (read-only in Sirius). Every downstream consumer
  keeps its input. Block 3 revisits when Deadlines moves to work cards.
- **D2** The deliverable-scoped urgency/difficulty routes are DELETED, not
  kept beside the new ones — a dormant write path is how this defect
  survives. A main-card id on the work-card route is a 404 (cross-kind test).
  A main card's labels change in Trello only, and reconcile in.
- **D3** `kpi.urgent` counts urgent WORK cards project-wide (unattached ones
  included). Asked of Miles in the reply owl; one line to change.
- **D4** `col-due` → `col-deadline` in lockstep (constants, both row kinds,
  CSS width rule, tests). The W2 picker stays inside it until block 3.
- **D5** `PIPE_FILTERS` keeps TYPE and STATUS only until block 4 rebuilds
  URGENCY/DIFFICULTY on work-card values with auto-expand. A dead axis that
  filters parents by an invisible value is worse than a missing one.
- **D6** contracts/trello-write.md gains a dated W1/W3 scope-clarification
  block (2026-09-05) parallel to §W2; the registry table's surface column
  reads "Pipeline urgency control (work-card rows)" / "Pipeline difficulty
  control (work-card rows)".
- **D7** The Pipeline search blob drops `requestor` (its column is gone).
- **D8** UNATTACHED tile label becomes `UNATTACHED CARDS` (the node's string).
- **D9** The `⚡` prefix goes; the node's label is `Urgent` and the only icon
  is the chevron.
- **D10** Badge label colours from the nodes (Easy green-600, Medium amber-600,
  Hard red-500; fills green-100 / amber-100 / red-50) supersede owl #04's
  "50 fill / 500 text" recipe. Medium/Hard rest on the component-set variants
  because the frame instantiates only Easy — flagged to Miles.
