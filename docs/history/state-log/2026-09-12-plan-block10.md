## 2. Frozen interfaces

Frozen here and nowhere else.

### A1 — `pipeTiles`, the one new computed
Returns `{ pending, ongoing, done, urgent }`, four numbers. Reads `pipelineRows`,
`workCardsByMc`, `pipeWorkLive`, `pipeFilters`.

- **Walks the distinct `mcNumber` values present in `pipelineRows`, once each.** Per-row
  iteration is forbidden: `r.work` is the SAME array object across sibling rows
  (`80-loaders.js:293`), so walking rows multiplies an MC's cards by its sibling count — up
  to 99× on MC-825.
- **Drops `status === 'excluded'` before bucketing, URGENT included** (drift D2). Ops work
  is not Frost's work, and an urgent ops card must not inflate a Frost figure.
- **Under a live work-card axis, counts only the cards that axis admits** (drift D4),
  through the existing `pipeWorkMatch` predicate — never a second copy of it.
- **URGENT is cross-cutting**: counted over the same set, never added to the other three.
- Unattached work cards belong to no row, so they fall out of every tile by construction.
  That is correct and intended — §4.0 sends them to ingestion health.

`kpi` is **retired**. Its `main` / `work` / `unattached` / `unattachedMcs` fields lose their
only consumer. `unattachedWork.cards` keeps its Sprint Schedules consumer untouched
(`40-schedules.html:38`) — no agent goes near that file.

- Labels are literal uppercase text: `PENDING` `ONGOING` `DONE` `URGENT`.
- The UNATTACHED tile and its `title=` tooltip are deleted whole.

- `.metric.quiet` is deleted with its tile.
- New tokens in `05-tokens.css`: `--yellow-600: #ca8a04` and `--emerald-600: #059669`.
