## Review-fix round (2026-09-11; REVIEW: F1 high + F4 low stood, F2 split ruled, F3 killed)
- **F1 (high) — reserved labels.** `setClassification` refuses with reason `'reserved'` any resolved tag whose label name is a registry-owned or kind-deciding taxonomy label: `Urgent` (W1), `/^Difficulty:\s*/i` (W3, the mapper's regex), `Main Card` (card kind), the 🛑 blocker prefix. DERIVE the set from the mapper/trello constants where they are exported (never a second copy); the same filter makes a reserved `previousTag` a silent skip. Guards: tag `'urgent'`, `' difficulty: easy '`, `'main card'`, `'🛑 blocked'` → refused, no POST; previousTag `'Difficulty: Hard'` → no DELETE.
- **F4 (low) — the failure branch must not depend on the store that just failed.** On failure write the `sync_runs` row FIRST, then the failure audit; guard the failure audit with `.catch` so nothing escapes; the header states the residual (a write that succeeded in Trello with both stores down is recorded nowhere until the next reconcile).
- **F2 (split, ruled) — no-op and canonical name.** The no-op compares NORMALISED (trim + case-fold) values; on success `unit_label` stores the board label's CANONICAL name (the resolved label's `name`), not the raw tag; `before`/`after` in the audit carry the stored values. Result shape unchanged.
- F3 killed (a 404 on the stale DELETE is already tolerated by the restore path; refuters proved the card ends in the original state).
